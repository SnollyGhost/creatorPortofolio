# Security Policy

## Reporting a Vulnerability

We take the security of this application and repository seriously. If you discover a security vulnerability, please report it privately rather than creating a public issue.

### How to Report
- **Email:** Send details to `nafyaddachasa91@gmail.com`
- **GitHub Private Vulnerability Reporting:** If enabled on this repository, submit a report via the **Security** tab -> **Report a vulnerability**.

### What to Include in Your Report
To help us triage and resolve the issue quickly, please provide:
1. **Description:** A detailed explanation of the vulnerability and its potential impact.
2. **Steps to Reproduce:** Exact steps, proof-of-concept (PoC) code, or HTTP request logs.
3. **Affected Components:** Specific files, API endpoints (`/api/*`), or dependencies involved.

### Our Commitment
- **Response Time:** We aim to acknowledge receipt of your report within 48 hours.
- **Resolution:** We will work to investigate, reproduce, and patch valid issues promptly.
- **Coordinated Disclosure:** We ask that you give us reasonable time to release a patch before disclosing any details publicly.

Thank you for helping keep this project safe!
